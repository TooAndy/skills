# 每月 AI Agent 案例报告生成器 — 设计文档

**日期**: 2026/04/27
**状态**: 已批准

---

## 1. 目标

为内部技术团队提供每月 AI Agent 领域最新应用案例的精选报告，帮助团队了解行业动态、竞品技术和可落地的实践经验。

---

## 2. 输出规格

### 2.1 报告格式

- **主格式**: Markdown 文件
- **命名规范**: `YYYY-MM-AI-Agent-案例报告.md`
- **案例数量**: 每月 5 个精选案例

### 2.2 每个案例的结构

| 板块 | 内容说明 |
|------|----------|
| 案例概述 | 是什么、背景、解决什么问题 |
| 技术栈 | 用了哪些模型、框架、工具 |
| 实现路径 | 核心架构、关键流程 |
| 效果数据 | 性能指标、收益量化（若有） |
| 技术亮点 | 值得学习的点 |
| 局限分析 | 不足、风险、约束条件 |
| 团队可借鉴点 | 我们能怎么用、什么时候用 |

---

## 3. 信源与评分

### 3.1 信源列表

| 信源类型 | 推荐渠道 |
|----------|----------|
| 技术社区/博客 | Hacker News、GitHub Trending、LangChain 博客、CrewAI 案例 |
| 行业媒体 | 机器之心、量子位、InfoQ、人人都是产品经理 |
| 产品更新 | OpenAI、Anthropic、DeepSeek 官方文档/案例板块 |
| 社交媒体 | Twitter/X（AI 从业者一手分享）、Reddit（r/LocalLLaMA、r/SideProject） |
| AI 导航站 | 未来百科、AI 产品精选 |
| 学术论文 | arXiv |

### 3.2 信源权重

| 信源 | 权重 |
|------|------|
| 官方博客/文档 | ⭐⭐⭐⭐⭐ |
| GitHub Trending + 技术博客 | ⭐⭐⭐⭐ |
| 行业媒体 | ⭐⭐⭐ |
| 社交媒体 | ⭐⭐ |
| arXiv 论文 | ⭐⭐ |

### 3.3 筛选标准

每个案例按以下维度打分（1-5 分）：
- **技术深度** — 是否有技术亮点值得学习
- **落地可行性** — 团队是否可以借鉴或复用
- **时效性** — 是否是当月最新
- **参考价值** — 对团队的产品/技术决策是否有帮助

取加权总分最高的 3-5 个案例进入报告。

---

## 4. 工作流程

### 4.1 触发方式

**手动触发，随时可运行**：
```bash
python generate_report.py --month 2026-03
```

### 4.2 执行步骤

1. **信息收集**：并行访问各信源，搜索目标月份的相关案例
2. **筛选评分**：按第 3.3 节标准打分排序
3. **报告生成**：按第 2.2 节模板结构生成 Markdown
4. **输出交付**：生成 `YYYY-MM-AI-Agent-案例报告.md`

### 4.3 格式转换（按需）

提供转换脚本：
- Markdown → HTML（用于内部门户展示）
- Markdown → Notion 兼容格式（用于知识库导入）

## 5. 技术选型

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 脚本语言 | Python 3.12+ | 生态最丰富 |
| 报告模板 | Jinja2 | 结构化生成 Markdown |
| 信源获取 | requests + BeautifulSoup | 网页爬取 |
| RSS 订阅 | feedparser | 解析 AI  Newsletter RSS |
| 格式转换 | pandoc | Markdown → HTML/其他格式 |
| 依赖管理 | pip / uv | 轻量化 |
